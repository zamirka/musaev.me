# musaev.me

Личный сайт: резюме, проекты, блог и архив дайджестов. Hugo, своя тема, ноль JS на страницах.

## Как запустить локально

```
npm run dev          # hugo server -D на localhost:1313
npm run build        # сборка в public/
npm run cv:pdf       # public/cv.pdf из /cv/print/ (нужен собранный public/)
```

Один раз после клона: `npm install && npx playwright install chromium`.

## Как что менять

| Что | Где |
|---|---|
| Резюме (страница и PDF) | `data/cv.yaml` – единственный источник, менять только здесь |
| Список проектов | `data/projects.yaml` + страница в `content/projects/<slug>.md` |
| Вишлист | `data/wishlist.yaml`. Вычеркнуть позицию – поставить `taken: true` |
| Статья в блог | новый файл `content/blog/<slug>.md`, имя файла = адрес статьи |
| Обо мне, контакты | `content/about.md`, `content/contacts.md` |
| Тексты разделов | `content/<раздел>/_index.md` |
| Внешний вид | `assets/css/main.css` |
| Счётчики, контакты, флаги | `hugo.toml`, секция `[params]` |

Дайджесты в `data/digests/*.json` кладёт бот – руками их трогать не нужно.

## Как это устроено

- **Резюме.** `data/cv.yaml` рендерится в три вида: `/cv/` (кратко), `/cv/full/` (полностью)
  и `/cv/print/` (печатная версия, из которой скрипт делает `/cv.pdf`). Рассинхрона между
  страницей и PDF не бывает по построению.
- **Дайджесты.** Content adapter `content/digest/_content.gotmpl` строит по странице
  на каждый JSON из `data/digests/`. Отдельные выпуски отдаются с `noindex`
  (флаг `params.digest.noindex`), раздел и RSS – открыты.
- **GitHub.** `layouts/_partials/github.html` тянет список репозиториев на сборке
  и вшивает в HTML. Если API недоступен – берётся снимок `data/github_fallback.json`,
  сборка не падает. Обновить снимок можно вручную, скопировав ответ API.
- **Фото.** Оригинал лежит в `assets/img/zamir.jpg`, все размеры Hugo делает сам.
- **Две ширины колонки.** Тексты (статьи, резюме, «Обо мне», контакты) читаются в узкой
  колонке `--measure`, списки и витрины (главная, блог, дайджест, проекты, вишлист) –
  в широкой `--measure-wide`, чтобы не гнать контент вниз при пустых полях по бокам.
  Страница может попросить другую ширину через `wide: true` / `wide: false` во фронтматтере.
- **Тема.** По умолчанию следует за настройками системы. Кнопка в шапке переключает
  вручную по кругу: как в системе → светлая → тёмная, выбор запоминается в браузере.
- **Архив дайджестов.** Выпуски, опубликованные ботом до появления сайта, перенесены
  разовым скриптом `scripts/import-telegraph.py` (нужен `TELEGRAPH_TOKEN`).
